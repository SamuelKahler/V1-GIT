# Installation

1. Keep the existing backup branch.
2. Unzip this repository.
3. Open the current GitHub-connected local repository folder.
4. Delete all visible files and folders inside it, but do not delete the hidden `.git` folder.
5. Copy every file and folder from this clean repository into the emptied repository folder.
6. Open GitHub Desktop and confirm the repository is still on `main`.
7. Commit with: `Install clean Sports Edge V2 foundation`
8. Push to GitHub.
9. Wait for Vercel to show Ready.
10. Hard-refresh the live website and verify MLB, F5, Series, Trends, and NFL.
