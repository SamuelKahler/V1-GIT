# Changelog — Version 11.1.0 / Phase 2A

## Added

- independent MLB Intelligence database foundation
- official MLB schedule and live-feed importer
- permanent `game_pk` deduplication
- final and first-five score storage
- inning, pitcher, team, venue, run, and error storage
- protected import, status, and audit APIs
- dry-run import mode
- bounded 1–7 day test imports
- automated syntax and transformation validation
- installation, validation, audit, and rollback documentation

## Unchanged

- customer-facing UI
- MLB/NFL/CFB navigation
- Sports Edge picks and grading
- performance tabs and calculations
- stored trend presentation
- existing `pick_observations` database
