# Sports Edge V23 - Clean Details + Conservative Grading

## What changed
- Removed the confusing `Other` category from consumer-facing displays.
- No default unit sizes are assigned anymore.
- Plays without explicit units still count toward W/L record when verified, but do not affect units or ROI.
- Added June 22 final-score verification for full-game markets.
- Added conservative F5 verification for the June 22 TB and MIL F5 plays.
- Cubs/Mets June 22 was treated as no action/postponed where applicable.
- Main pick cards are cleaner and no longer dump full reasoning text.
- Pick details now use expandable sections:
  - Matched Trend Evidence
  - Starting Pitcher / K Prop History
  - Edge Type / Notes
  - Verification
  - Model / Component Breakdown
  - Why This Matters

## Data-quality rule
If a result cannot be verified from final score, first-five linescore, series result, or stored prop history, the app does not guess.
