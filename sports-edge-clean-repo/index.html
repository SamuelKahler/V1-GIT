Grade A Logic

Current Qualification Rules

  • Grade A: custom score 7.00 or higher.
  • Playable: custom score 6.50 to 6.99.
  • Pass/Fade: below 6.50 or price/risk fails discipline.
  • Favorite odds cap: avoid prices worse than -150.

This prototype uses the pick component data already entered into the app. In production, the same sliders should recalculate every eligible live slate bet.
