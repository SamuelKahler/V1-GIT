# Sports Edge V14 - Compact Scenario History

## What changed
- Removed the large scenario history block from the top of the Trend Database results area.
- Today's matching trend rows now stay primary on the page.
- Each trend row includes an expandable history dropdown inside Result Evidence.
- The dropdown shows stored historical rows for the exact team/style scenario.
- Current-slate matchup context remains visible without overwhelming the page.

## Why
The Trend Database should first show the exact style/category the user is looking for on today's slate. Historical context should support the row, not take over the page.
