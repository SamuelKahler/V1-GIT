# Sports Edge V36 — Series + Performance Cleanup

Built from V35 with only the requested tweaks:

- Series Board methodology dropdown moved to the top of the Series Board.
- Removed the duplicate static Series Board dropdown.
- Series cards now include a result badge placeholder: WIN / LOSS / PUSH when stored, otherwise Series Pending.

- Performance Dashboard now uses flat 1U accounting for every displayed tracked bet.
- Spread and Parlay are hidden from Performance Dashboard display but remain preserved in the data.
- Performance Lab is split by month, newest first.
- Research Journal is sorted newest to oldest.
