# GitHub Upload Steps

## Option A: Start Fresh Repository

1. Download the clean repo ZIP.
2. Unzip it on your computer.
3. Go to GitHub.
4. Create a new repository named `sports-edge-app`.
5. Upload all files from the unzipped folder.
6. Commit with message: `Initial clean Sports Edge repository`.

## Option B: Replace Current Repository

1. Back up the current repository first.
2. Delete the cluttered root files.
3. Upload this clean structure.
4. Commit with message: `Clean repository structure`.

## Recommended Branches

- `main` — stable live app.
- `daily-updates` — daily picks and data updates.
- `feature/<name>` — feature changes.

## Commit Message Examples

- `Add 06-29 MLB picks`
- `Update NCAA football prop database`
- `Improve Series Board layout`
- `Fix matched trend evidence filter`
