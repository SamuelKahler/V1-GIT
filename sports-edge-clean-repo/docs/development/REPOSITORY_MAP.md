# Sports Edge Repository Map

## Root App Files

- `index.html` — main app shell.
- `styles.css` — full visual styling.
- `app.js` — rendering, navigation, filtering, details panels, logic.
- `data.js` — all current embedded data: picks, trends, research journal, performance, series board, NCAA props.

## Documentation

- `docs/releases/` — version notes from V16 onward.
- `docs/roadmap/` — long-term app roadmap and live-data roadmap.
- `docs/development/` — workflow, GitHub, Vercel, and update rules.
- `docs/ideas/` — future model ideas and notes.

## Backend / Database Prep

- `db/` — Drizzle schema and DB entry files.
- `sql/` — migrations copied out of Netlify folders for easier access.
- `integrations/netlify/` — old Netlify function/database files preserved as reference.

## Legacy Scripts

- `scripts/legacy-patches/` — old patch scripts. Keep for reference, but do not use for daily updates.
