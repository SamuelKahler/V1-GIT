# Custom F5 Model Engine V1B

## Changed
- Range sliders now support true continuous 0–100% movement.
- Fixed V1A DOM re-render bug that interrupted drag gestures after a one-point change.
- Added proportional auto-balancing to keep the model at exactly 100% while editing.
- Added manual mode plus Normalize action.
- Added direct numeric entry and ±5 controls for precise weighting.
- Expanded backend factor validation from a 60% maximum to a 100% maximum.
- Added four starter presets.
- Persisted custom weights to local browser storage.
- Added a global Model Lab launcher and slide-in sidebar.
- Added compact top-edge output to the sidebar.

## Unchanged
- Model Lab runs remain experimental and separate from Official Sports Edge performance.
- No picks, grades, historical games, trend evidence, or Supabase data are modified by this release.
