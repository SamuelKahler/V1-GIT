# Sports Edge V38 — College Football Prop Database

Built forward from V37 without changing the MLB pick flow.

## Added
- New College Football sport card on the home screen.
- New CFB top navigation shortcut.
- New College Football Prop Lab theme with football-specific color system.
- Imported NCAA football player prop database from the uploaded 2025 prop-tracking file.
- Added team search and team dropdown.
- For every selected team, users see player dropdowns grouped by player.
- Each player card shows:
  - position
  - team
  - new-team flag when stored
  - prop types
  - current prop line placeholder
  - lines/odds that hit
  - lines/odds that missed
  - user-tracked hit rate when available

## Product Direction
The College Football page follows the same Sports Edge philosophy as MLB, but with a prop-first workflow:

1. Choose sport.
2. Search team playing today or any team in the database.
3. Open players on that team.
4. Compare current prop line against last-year hit/miss history.

## Not Changed
- MLB Today's Picks
- MLB Series Board
- MLB Performance Lab
- MLB Bet Details
- MLB Trend Database

## Future Data Hook
When live college football schedule and prop lines are available, today's teams can be surfaced first and current prop lines can populate automatically.
