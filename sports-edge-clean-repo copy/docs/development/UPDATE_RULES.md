# Sports Edge Update Rules

## Do Not Change Unless Requested

- MLB card layout
- Bet Details structure
- Series Board method dropdown
- Performance Dashboard monthly layout
- College Football sport page structure
- Sport-first homepage

## Daily Updates Should Only Touch

- `data.js`
- `docs/releases/README_VXX_*.md` if adding a release note

## Feature Updates May Touch

- `app.js`
- `styles.css`
- `index.html` only if absolutely necessary

## Data Rules

- Do not invent unit sizes.
- If the current product rule says flat 1U, use the current global performance rule consistently.
- Keep spread/parlay data preserved even when hidden.
- Keep Research Journal sorted newest to oldest.
- Matched trend evidence must match the exact stored situation.
