# Sports Edge V21 - Betting Intelligence Dashboard

## Product mindset
V21 is built from the daily bettor/customer mindset: users should immediately see what matters today, then optionally dig into the research.

## Main updates
- Homepage now asks: "What should I look at today?"
- Today's card separates official unit-sized plays from research-only plays.
- Series plays are moved into the Series Board lane instead of being mixed into the main daily card.
- Added Performance Lab for actual money-bet history.
- Imported the official betting ledger supplied by the user as `officialBetHistory`.
- Performance Lab shows record, net units, ROI, bet count, category strength, and a searchable bet log.
- Series Board remains a clean card system with pick, price, edge, grade, and why.
- Model Center demo unlock now opens the model page and scrolls users to the weight sliders.

## Data rules
- Unit-sized / result-ledger plays are official betting history.
- Research plays are edges found by the app or entered by the user that do not yet have unit sizes attached.
- Series plays live in Series Board first, not mixed into main F5/ML/Over/Under cards.
- Verified grading logic from V19 is preserved.

## Customer clarity rule
Every page should answer: "What am I supposed to do with this information?"
