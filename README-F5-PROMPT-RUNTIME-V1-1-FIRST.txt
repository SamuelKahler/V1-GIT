F5 Prompt Runtime V1.1 — Full Slate Intelligence

Purpose
- Make every customer model run useful even when zero wagers clear the Top Play gates.
- Preserve the canonical eight-category F5 prompt and all hard rules.
- Add deterministic Top Play / Near Miss / Pass-Fade segmentation.
- Add a slate-level diagnosis, exact failed-gate deltas, and verified historical support from the MLB backbone.
- No additional AI call is required to expand evidence from a completed run.

Customer result structure
1. Today's Model Read
2. Top Plays (cleared every gate)
3. Near Misses (missed exactly one core gate)
4. Pass / Fade board
5. Verified historical support on each candidate
6. All eight category scores and rationales
7. Research sources

Credit philosophy
One new model computation is one run. Expanding evidence, near-miss explanations, sources, or historical support reuses the completed run and should not consume another model computation.
